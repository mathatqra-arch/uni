## 🔄 نظام المزامنة (Offline-First)

### كيف يعمل:

```
1. أول تثبيت:
   المتصفح ← API ← يبني قاعدة محلية كاملة (Dexie/IndexedDB)
   • 72 منتج، 26 فئة، 20 عميل، 20 إعداد

2. أثناء البيع (offline):
   • الكاشير يبيع ← يُحفظ في Local DB فوراً
   • المخزون يُحدّث محلياً
   • نقاط الولاء تُحدّث محلياً
   • العملية تُضاف لـ syncQueue

3. عند عودة الإنترنت:
   Sync Engine ← يرفع syncQueue إلى Supabase
   Sync Engine ← يسحب التحديثات من Supabase
   • Idempotency: clientId يمنع التكرار
```

### الملفات:
- `src/lib/local-db.ts` - قاعدة Dexie محلية (9 جداول)
- `src/lib/supabase.ts` - عميل Supabase + export/import
- `src/lib/sync-engine.ts` - محرك المزامنة الثنائي

## 🚀 خطوات التشغيل

### 1. التطوير المحلي
```bash
bun install
bun run db:push              # إنشاء قاعدة SQLite
# لا يوجد seed تلقائي لبيانات الأعمال؛ يبدأ النظام ببيانات فارغة
bun run dev                  # تشغيل على http://localhost:3000
```

### 2. ربط Supabase (للمزامنة السحابية)
1. أنشئ مشروع على [supabase.com](https://supabase.com)
2. في SQL Editor، نفّذ محتوى `supabase-schema.sql`
3. من Settings → API، انسخ URL و anon key
4. أدخلهما في:
   - ملف `.env` (للإعداد الدائم)
   - أو من واجهة الإعدادات ← تبويب المزامنة

### 3. النشر على Vercel
1. ارفع المشروع على GitHub
2. اذهب إلى [vercel.com](https://vercel.com)
3. Import Repository
4. أضف متغيرات البيئة
5. Deploy
